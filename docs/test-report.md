# 单元测试报告

运行命令：

```text
npm test
```

测试程序位于 `tests/domain.test.js`，使用 Node.js 内置 `assert`，没有引入额外依赖。当前共 13 个测试用例，覆盖以下场景：

1. 关键词规范化。
2. 按物品名称搜索。
3. 按地点和描述搜索。
4. 按寻物/招领类型筛选。
5. 按处理状态筛选。
6. 无匹配结果。
7. 必填项缺失校验。
8. 完整表单校验。
9. 新建信息默认值。
10. 更新目标信息状态。
11. 修改信息字段。
12. 时间格式化。
13. 首页统计数量。

测试结果：13/13 通过。

除单元测试外，浏览器手工检查了首页浏览、搜索、详情、联系提示、发布校验、发布成功、我的发布、修改、删除、状态更新和刷新后数据保留等流程。
