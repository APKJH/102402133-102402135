# 数据与模块说明

## 数据结构

每条物品信息使用一个 JavaScript 对象表示：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一标识，用于详情、修改和状态更新 |
| `owner` | 发布者标识，演示中使用 `tan` 区分“我的发布” |
| `type` | `寻物` 或 `招领` |
| `category` | 校园卡、钥匙、电子设备、书籍等类别 |
| `title` / `place` / `time` | 物品名称、地点和发生时间 |
| `description` | 物品特征与线索描述 |
| `status` | `待处理`、`已找到`、`已归还` |

## 模块划分

- `src/domain.js`：纯函数业务规则，包括搜索、筛选、表单校验、创建、修改、更新状态和统计。
- `src/data.js`：课程演示种子数据。
- `src/app.js`：页面导航、DOM 渲染、表单事件和 `localStorage` 持久化。
- `src/styles.css`：响应式页面布局和组件样式。
- `tests/domain.test.js`：不依赖浏览器的 Node.js 单元测试。

## 关键实现思路

程序将业务规则与界面操作分离，搜索和校验函数可以独立测试；页面事件只负责读取表单、调用业务函数和刷新视图。数据写入浏览器 `localStorage`，刷新页面后仍能保留本次演示中新增、修改和状态变化的记录。
